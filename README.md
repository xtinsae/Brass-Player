# Brass-Player

Brass Player is an offline audio engine.

Brass-Player is a modern offline music player built for a fast, smooth, and distraction-free listening experience. Designed with a clean interface, fluid performance, and an evolving feature set, Brass-Player focuses on delivering high-quality local audio playback while remaining lightweight and easy to use.

⚠️ This project is currently under active development. Features, UI, and functionality may change as the project continues to evolve.
